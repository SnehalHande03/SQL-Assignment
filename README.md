# 🏨 Hotel Management SQL Assignment

## 📌 Overview

This project contains a collection of SQL queries designed for a **Hotel Management System**.
The queries cover real-world business scenarios including guest management, booking analysis, revenue tracking, and database operations.

---

## 🗂️ Database Tables Used

* **HotelGuest** – Stores guest details
* **HotelBooking** – Stores booking information

---

## 🚀 Key Features / Tasks Covered

### 🔍 Data Retrieval

* Fetch active guests from a specific city
* List distinct guest cities
* Retrieve cancelled or no-show bookings
* Identify high-value bookings

### 🎯 Business Insights

* Analyze booking trends by status
* Revenue calculation by room type
* Booking analysis by channel
* Guest loyalty insights

### 🔗 Joins & Relationships

* Combine guest and booking data
* Identify guests with bookings
* Include guests without bookings using LEFT JOIN

### 📊 Aggregations

* Count bookings by status
* Calculate total revenue
* Average booking amount by channel
* Guests with more than 6 booked nights

### 🛠️ Database Operations

* Add new column (`GSTNumber`)
* Modify column data type
* Rename tables
* Update booking statuses
* Delete old records
* Truncate table data

### 👁️ Views

* `vw_ActiveGuests` – Active guest details
* `vw_BookingSummary` – Booking overview

### ⚙️ Advanced Concepts

* Stored procedures (planned)
* Date-based filtering (e.g., December 2024 bookings)
